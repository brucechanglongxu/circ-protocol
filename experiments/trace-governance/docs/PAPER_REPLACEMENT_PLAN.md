# Replacement for the Current Illustrative Simulations

The revised Perspective should remove all performance-like toy simulation claims and use this work in
three clearly separated roles.

## Main-text empirical component

**Trace-based risk detection in clinical-agent investigations.** Apply the frozen risk taxonomy to
CliniCARE process rubrics and protected execution traces. Report which risk families are observable,
criterion applicability, natural rubric-trigger rates, and uncertainty. Describe this as a study of
retrospective audit traces, not a multi-agent deployment evaluation.

## Control stress test

Use matched trace perturbations to estimate whether independent scope, dependency, and provenance
controls detect prespecified faults while preserving unmodified work. Report the full factorial rather
than arranging controls into levels. The primary figure should place fault containment against base
preservation with confidence intervals and explicit denominators.

## Figures

1. **Risk-to-control map:** non-exhaustive healthcare agent risk families, observable CliniCARE
   criteria, candidate governance controls, and untested risks shown explicitly.
2. **Matched replay design:** one base trace, clean and faulted twins, eight control arms, dual primary
   endpoints. This is an architecture and study-design figure, not a performance result.
3. **Confirmatory results:** containment and preservation by lever and fault family. Include natural
   rubric-trigger rates only after protected analysis and codebook double review.

Resource congestion, agent-to-agent conflict, cross-organizational identity, human response, and
clinical outcome effects remain future work unless RecordTime or another appropriate trace source is
added. CliniCARE must not be presented as evidence for those claims.
